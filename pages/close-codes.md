# Close Codes

| code | meaning |
|---|---|
| 4000 | unknown error (including e621 being unreachable while verifying credentials) |
| 4001 | unknown op |
| 4002 | invalid JSON or payload |
| 4003 | not identified (timed out, or sent something before identify) |
| 4004 | authentication failed |
| 4005 | already identified |
| 4006 | invalid subscription |
| 4007 | invalid cursor |
| 4008 | rate limited (more than 60 messages a minute) |
| 4009 | slow consumer: you fell too far behind, so reconnect with your last cursor |
| 4010 | too many connections (per IP or per e621 account) |
| 4011 | credentials are no longer valid |
